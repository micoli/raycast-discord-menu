# Raycast Discord commands and menu bar

Tested on MacOS

Communications between raycast extension and discord are made through devTools remote debugging en discord app, so discord application must be either launched through:
- the `Launch Discord` command or menu item, which also relaunches Discord when it runs without the debugger
- `open -a Discord --args --remote-debugging-port=5656 --remote-allow-origins=*`

The injected script is installed and updated automatically by the commands (also after each Discord reload), there is nothing to inject by hand.
Discord needs the macOS `Screen & System Audio Recording` permission to list screens in the share picker.

The menu bar icon shows the screen share, microphone, sound and voice member count states (refreshed within ~0.6s when the discord state changes by a small background process (`assets/discord-watcher.js`, started by the extension, logs in the extension support folder) that listens to discord and opens the menu deeplink with `open -g`, and every minute as a fallback). Icons (2x2 grid: logo or screen share, microphone, sound, member count) are generated by `npm run build-icons` (needs `rsvg-convert`) and committed in `assets/menu-icons`.

Commands: stream screen 1 / 2, stop stream, toggle / mute / unmute microphone, toggle / deafen / undeafen speaker, voice members (who is in your current voice channel), launch / stop Discord.

## Installation

```
cd ~/src
git clone https://github.com/micoli/raycast-discord-menu
cd raycast-discord-menu
npm install && npm run dev
```
